# 组件规范（components.md）

所有尺寸基于 13px 正文、4px 栅格。实现时前端统一封装 `PageTable` / `StatusTag` / `Uploader` / `PermissionBtn` / `formatTime`，禁止逐页重复实现。

## 按钮 Button

| 类型 | 高度 | 内边距 | 背景 | 文字 | 边框 | 用途 |
|---|---|---|---|---|---|---|
| Primary | 32px（大号 36） | 0 16px | `#0F4C5C` | `#fff` | 无 | 每屏 1 个主操作 |
| Secondary | 32px | 0 16px | `#fff` | `#0F4C5C` | 1px `#C6D9DA` | 次级操作、取消 |
| Text | 32px | 0 8px | 透明 | `#315F66` | 无 | 表格行内「查看」 |
| Danger | 32px | 0 16px | `#fff` | `#B02A37` | 1px `#E3B4B8` | 驳回、删除、作废 |

- 圆角 6px；禁用态 `opacity:.45` + `cursor:not-allowed`
- hover：主按钮加深至 `#0B3A46`；次按钮底色 `#EAF3F3`
- 行内最多「查看 + 2 个高频操作」，其余收进「更多 ⋯」

## 表单 Form

- 标签右对齐或顶对齐；标签宽 100–120px，必填项前加红色 `*`
- 输入框高 32px，内边距 `0 10px`，描边 `#C6D9DA`，聚焦 `#2A7F86` + 2px 浅青外环
- 下拉框宽 **180–240px**；日期用日期选择器、组织用级联选择器，禁止普通文本框替代
- 校验：失焦即时提示，提交时汇总；错误文案 12px `#B02A37`，紧贴控件下方
- 抽屉内表单支持「保存草稿」，关闭前检测未保存内容

## 表格 Table

- 表头：高 44px，底色 `#F5FAFA`，字 12px `#5C7379`，左对齐（数字列右对齐）
- 行高 44px，行底边 1px `#EDF4F4`；hover `#F7FBFB`
- **表头不写死宽度**：`th{white-space:nowrap}` + `min-width`，容器 `overflow-x:auto`
- 编号、状态、日期、操作列单行不换行；长文本列最多 2 行省略
- 分页：默认 10 条，可切 20/50；切换筛选条件后回第 1 页

## 卡片 Card

- 白底，1px `#DCE7E8`，圆角 8px，内边距 16px，无阴影
- 卡片标题 15px/500，右侧可放筛选或「查看全部」文字链
- 指标卡：标签 12px 灰 + 数值 26px/600 主色 + 环比小字（升红降绿按中国习惯）

## 标签 StatusTag

| 状态 | 底色 | 文字 |
|---|---|---|
| 待执行 / 草稿 | `#EEF2F3` | `#4B6167` |
| 待复核 / 处理中 | `#FBF1E2` | `#A66A1E` |
| 异常 / 驳回 | `#FBEAEC` | `#B02A37` |
| 已确认 / 已归档 | `#E7F2EC` | `#247451` |
| 信息类 | `#E8F1F3` | `#315F66` |

高 22px，内边距 `0 8px`，圆角 4px，字号 12px，可与圆点图标组合。

## 弹窗 / 抽屉 Modal & Drawer

- 抽屉宽 480px（详情 640px），右侧滑出，遮罩 `rgba(11,58,70,.32)`
- 审批类抽屉上部固定单据摘要（编号 / 状态 / 责任人 / 截止时间），下部为操作区
- 危险操作二次确认弹窗：标题「确认驳回该抄表记录？」，正文写清影响，主按钮红色

## 分页 Pagination

- 高 32px，页码按钮 32×32，当前页主色实心
- 左「共 N 条」，右「页码 + 每页条数 + 跳转」

## 上传 Uploader

- 拖拽区虚线 1px `#C6D9DA`，圆角 8px，高 120px，图标 + 「点击或拖拽上传，支持 jpg/png，≤5MB」
- 已上传显示缩略图 + 文件名 + 大小 + 删除；**页面不出现要求手填图片 URL 的输入框**
- 后端保存相对路径、原始文件名、大小、上传人

## 图表 Chart

- 折线：线宽 2px，点半径 3px，网格虚线 `#E8F0F0`，Y 轴从 0 起
- 柱状：圆角 2px，宽 ≤24px，组距 12px
- 环图：内径 62%，中心显示总计，图例右侧竖排
- 统一 tooltip：白底、1px 描边、12px 字；图表点击跳转带筛选条件的列表

## 时间与数字

- 全局 `formatTime(v)` → `yyyy-MM-dd HH:mm:ss`；日期列 `yyyy-MM-dd`
- 金额：`¥` + 千分位 + 2 位小数；用量：千分位 + 单位（kWh / m³ / GJ）
- 空值统一显示 `—`，不显示 `null` / `undefined`
