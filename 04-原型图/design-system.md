# 能耗抄表与节能分析系统 · 视觉规范（Design System）

> 依据需求文档「UI 视觉与交互设计」一节落地。方向：**深海青 · 专业业务系统**。
> 原则：数据可读性优先、操作效率优先、状态可辨识；不做巨幅英文口号、装饰光效、悬浮球、大面积插画。

## 1. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--c-primary` | `#0F4C5C` | 顶部栏、主按钮、当前菜单、关键指标数字 |
| `--c-primary-deep` | `#0B3A46` | 侧边栏底色、主按钮 hover |
| `--c-secondary` | `#2A7F86` | 次级按钮、筛选选中态、普通图表系列 |
| `--c-accent` | `#315F66` | 链接、信息提示、图表对比系列 |
| `--c-bg` | `#F3F8F8` | 主内容区背景 |
| `--c-surface` | `#FFFFFF` | 卡片、表格、表单容器 |
| `--c-border` | `#DCE7E8` | 分割线、表格边框、输入框描边 |
| `--c-text` | `#16323A` | 正文与标题 |
| `--c-text-2` | `#5C7379` | 次要说明、表头、辅助信息 |
| `--c-success` | `#247451` | 已完成 / 已通过 / 正常 |
| `--c-warning` | `#A66A1E` | 待复核 / 超时预警 / 偏高 |
| `--c-danger` | `#B02A37` | 驳回 / 异常 / 删除确认（仅小面积） |

图表色序（同一含义跨页面保持一致）：
`#0F4C5C`（电）→ `#2A7F86`（水）→ `#315F66`（燃气）→ `#7FA6A9`（冷热量）→ `#C2D6D7`（其他）。

**状态不得只靠颜色表达**，必须同时出现中文标签或图标（表格内为文字标签，图表内为图例 + 数据标签）。

## 2. 排版

- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`
- 数字列：`font-variant-numeric: tabular-nums`，等宽对齐，避免金额/读数跳动
- 阶梯：页面标题 20/28 semibold · 卡片标题 15/22 medium · 正文 13/22 · 表格 13/20 · 辅助 12/18
- 字重只用 400 / 500 / 600 三档，不使用 700 以上

## 3. 间距与栅格

- 基准 4px；常用 8 / 12 / 16 / 24 / 32
- 内容区外边距 24px，卡片内边距 16–20px，表单项纵向间距 16px
- 桌面框架：左侧菜单 **220px**（折叠 64px）+ 顶部栏 **56px** + 自适应内容区
- 表单标签宽 100–120px，单列输入宽 360–520px，搜索下拉框宽 180–240px

## 4. 形状与阴影

- 圆角：卡片/容器 8px，按钮/输入框 6px，标签 4px，头像圆形
- 阴影：仅抽屉 `0 8px 32px rgba(15,76,92,.16)` 与弹窗 `0 12px 40px rgba(15,76,92,.20)`；卡片用 1px 描边 `--c-border` 代替阴影
- 分割线 1px `--c-border`，不使用双线或粗边框

## 5. 组件基调

- **按钮**：主按钮实心主色；次按钮白底主色描边；危险操作红色描边，二次确认；文字按钮仅用于「更多」类低频入口
- **状态标签**：浅底 + 深字 + 4px 圆角，字号 12；`待执行` 灰蓝、`待复核` 琥珀、`异常` 红、`已确认/已归档` 绿
- **表格**：表头 12px 灰字、行高 44px、斑马纹关闭、hover 浅青；表头不写死宽度，`min-width` + 横向滚动
- **图表**：无 3D、无渐变填充堆叠；折线 2px，柱状圆角 2px，环图内径 62%
- **空状态**：说明产生原因 + 下一步动作，例如「当前筛选条件下无记录，可清空筛选或新建抄表任务」
- **加载**：>300ms 显示骨架屏或表格 loading，禁止整页白屏

## 6. 角色视觉区分

| 角色 | 框架 | 强调方式 |
|---|---|---|
| 系统管理员 | 后台管理（深青侧栏 + 顶栏） | 菜单含系统设置分组，主色实心 |
| 能源管理员 | 后台管理 | 顶栏右侧显示「全域数据」范围徽标 |
| 用能部门联络员 | 后台管理（浅色侧栏） | 侧栏顶部显示部门名，全局只读本单元 |
| 抄表员 | 移动作业风格（顶部 Tab 导航） | 大按钮、任务卡片流、底部固定操作区 |

## 7. 响应式

- ≥1200px：完整侧栏 + 多列指标
- 768–1199px：侧栏折叠为图标条，指标 2 列
- <768px：侧栏改抽屉，筛选折叠为底部面板，表格转信息卡片（仅编号/状态/时间/负责人），点击进详情；点击区域 ≥44px，底部操作区不遮挡分页
